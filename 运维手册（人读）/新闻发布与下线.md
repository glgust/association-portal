# 新闻发布与下线

从后台“内容管理 → 新闻”新建。需要内容创建/编辑权限，发布和下线另需直接发布权限。

1. 填写单行标题、可选单行摘要和正文。正文使用现有富文本工具，不包含图片、附件、脚本或嵌入内容。
2. 保存草稿。公开 `/news` 不显示新草稿。
3. 核对后发布，从 `/news` 打开详情检查正文及发布时间。时间按中国标准时间显示。
4. 修改内容并保存草稿时，访客继续看到旧版；发布变更后才更新，每次发布都会刷新发布时间及排序。
5. 撤下时使用文档菜单的下线（Unpublish）并确认。列表移除，旧地址为 404。

标题修改不改变创建时生成的路径。不能通过改 slug、清空正文或物理删除代替下线。从未发布和已经下线的新闻不能重复下线。

发布被拒绝时检查单行约束、长度、空正文和不受支持的节点。403 请账号管理员检查状态及权限；公开端故障按[运维排错](README.md#启动失败时)处理。内容修改记录查看版本，发布/下线记录由有审计权限的人在审计事件中查看。
