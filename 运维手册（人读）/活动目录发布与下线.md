# 活动发布、取消与下线

登录后台“内容管理 → 活动目录”。需要内容创建/编辑权限；发布和下线还需要直接发布权限。

1. 新建活动，选择“临时活动”或“常驻活动”。临时活动填写开始和结束时间，结束必须晚于开始；常驻活动填写开放时间说明。
2. 填写标题、地点、介绍和可选摘要。地点为纯文本，不是地图或报名组件。
3. 保存草稿，再核对活动类型及时间，发布后打开 Web `/activities` 并进入详情。公开时间按中国标准时间显示。
4. 修改已发布活动可以先保存草稿，旧公开版本仍保留；再次发布变更后才显示新版。

## 取消活动

勾选“已取消”，填写取消说明，保存并发布变更。活动仍出现在公开目录和详情中，并显示取消状态，方便访客获知变化。

## 撤下活动

在文档菜单选择下线（Unpublish）并确认。活动从目录移除，详情变为 404。只想告知取消时使用上面的取消操作；不要误下线。重复下线或对从未发布的草稿下线会被拒绝，此时刷新核对状态。

切换活动类型会清空不再适用的隐藏字段；从取消恢复正常会清空取消说明。发布前重新核对，不要依赖隐藏字段保存旧安排。摘要、开放说明和取消说明可换行；标题和地点必须单行。

字段错误按提示修正；403 请检查账号权限；公开端不可用请记录请求编号并按[运维排错](README.md#启动失败时)处理。不要直接修改数据库中的历史排序或版本字段。
