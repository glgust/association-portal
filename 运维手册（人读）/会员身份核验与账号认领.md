# 会员身份核验与账号认领

该流程服务于已完成协会线下流程的人，公开入口 `/account/claim` 不是开放招新登记。首次测试请使用虚构资料。管理员从“会员与账号 → 会员账号认领与人工核验”（`/admin/member-account-claims`）进入，需有效账号和相应账号管理权限。

## 路径一：已有会员，预配置后认领

1. 在线下核实身份。在“预配置待认领账号”中选择“关联既有正式 Member”并填写“已确认 Member ID”；可先从“会员与账号 → 会员档案”打开档案，取详情地址最后一段 ID，核对姓名和学号后再填。若是新会员，选择“线下面试通过并新建 Member”，填写姓名、学号、协会身份、主要联系方式及适用的专业，并完成线下确认。
2. 设置实际授予的会员、干事或干部身份。有学号的账号进入待认领状态；此时不会签发临时凭证。
3. 将本站 Web `/account/claim` 地址告知本人。本人填写核验信息、设置正式密码并提交后，账号进入待审批，尚不能登录。
4. 本人保存成功页面一次性显示的查询凭证，通过 `/account/claim/status` 查询进度。该凭证不能登录，也不是激活码。
5. 管理员在待处理队列中打开记录，与线下资料核对，选择“批准认领并激活账号”。账号直接生效，本人使用第 3 步设置的密码登录。

申请人选择的身份不会自行授予角色，批准以管理员当前预配置为准。没有学号的外部账号走[直接建号与临时凭证激活](后台账号与权限.md#为同事建立账号)。

## 路径二：无法匹配，先人工核验

1. 申请人在公开页进入人工核验并提交虚构测试资料，保存查询凭证。
2. 管理员在队列中打开“人工核验”，核对资料和既有 Member。
3. 批准时明确选择关联已有 Member 或创建 Member；需要采纳资料时先逐项核对。
4. **批准人工核验仅完成 Member 处理，不创建可登录账号。** 接着按路径一预配置认领，或为无学号者直接建立外部账号。

## 拒绝、补充说明与重新开放

拒绝时选择原因类别。对外说明单独填写，最多 300 字，申请人可以看到；不要写内部判断、私人资料或凭据。

账号认领被拒绝后进入阻止状态，旧密码与会话失效，敏感核验资料按流程清除。核实可以继续时，管理员“重新开放认领”，本人重新提交并设置新密码。人工核验被拒绝后，需要本人重新提交新申请。

终态处理会清除部分申请信息；有必要的线下记录应按协会自己的合法留存规则管理，不能依赖已处理列表永久保存完整资料。首版待处理记录的自动过期和完整个人信息保留策略尚未落地。

## 查询凭证丢失

已处理记录在原终态处理时间后 30 天内可“重新签发查询凭证”，旧凭证立即失效，有效期不会因重签延长。管理员从已处理列表找到记录后操作并安全交付。仍在待处理状态的申请不能重签查询凭证；应先通过可信渠道联系管理员核实，不要让申请人反复重复提交。

已处理列表每页 20 条，可以筛选需要跟进的记录或加载下一页。不要因首屏没有看到就判断记录丢失。

## 特殊情况：改为临时凭证激活

只有确需终止认领流程时使用“终止认领并转换为临时凭证激活”。先阅读并勾选页面列出的全部影响：原认领终止、此前密码/会话失效，账号待激活，新的 72 小时凭证只显示一次。安全交付本人后按登录页激活流程完成。

尚未激活时可以在专用页面重签凭证，或撤回转换；撤回会使临时凭证失效，并要求本人重新认领和设密码。不要把该动作当作正常批准的快捷方式。

提交返回 409 时刷新记录重新核对，403 请检查操作者权限和目标角色范围。停用认领中的账号会终止相应待处理流程并撤销会话，操作前先确认目的。
