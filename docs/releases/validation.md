## GitHub Actions 验证

开源仓库已接通真实 PostgreSQL 17.11 和 Chromium。首次完整运行已通过数据库迁移、E2E 账号初始化、574 项单元测试及两个应用的生产构建；浏览器测试发现的问题已进入修复，包括首页运行时数据、后台列表选择列、公告固定链接，以及中文界面选择器和测试数据准备。

发布工作流会重新执行迁移、测试数据初始化、构建及浏览器流程，并单独测试 CMS 不可用时的公开页面反馈。只有这些检查全部成功，才会创建 `v1.0.0` 首个测试版。最终结果以 [Actions 运行记录](https://github.com/glgust/association-portal/actions/workflows/check.yml) 和 Release 正文链接的对应提交检查为准；不能用其他提交的成功结果替代本版本验证。

本地整理环境没有 Docker 引擎和可用 PostgreSQL，数据库与浏览器闭环交由上述 CI 执行。文档对照源码及工作流核对，尚未逐步完成真实容器首次启动、外网部署和生产备份恢复。

未执行真实 S3 供应商验证、外网部署、长期负载或独立安全审计。构建成功和单元测试通过不构成生产可用性保证。
