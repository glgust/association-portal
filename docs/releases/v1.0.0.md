# v1.0.0 · 首个测试版

**这是首个测试版，尚未经过长期生产环境验证。GitHub Release 必须标记为 Pre-release。** 版本标签保持 `v1.0.0`，不会发布到 `stable` 镜像频道。

## 提供的功能

- 公开门户：首页、介绍、联系方式、公告、活动、新闻与单图画廊。
- 草稿、发布、更新和下线的内容版本流程。
- 后台账号激活、有效期、停用、权限覆盖和审计。
- 会员身份核验、账号预配置、认领审批及查询凭证恢复。
- 私有媒体上传、四种 WebP 展示图和按发布状态控制的公开读取。

## 开源版整理

- 独立仓库、独立 Git 历史与容器镜像名，不包含自用部署配置及内部工作记录。
- 重写 README、运维和内容编辑手册；增加不覆盖现有配置的随机演示初始化。
- 默认内容使用示例协会，移除指向原协会宣传站点的链接。
- 收紧历史动态表单答案契约，并对重复提交键核对请求内容；补充相应验证。
