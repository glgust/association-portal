# 公告发布与下线

先按 [README](../README.md) 启动并登录后台。初次测试使用 owner 账号；实际操作需要内容创建、编辑权限，公开与下线还需要 `content.directPublish`。

1. 从“内容管理 → 公告”新建公告，填写“标题”“公开摘要”（可选）和“正文”。正文使用编辑器已有的文字、标题、列表、引用和链接，不支持嵌入 HTML、图片或附件。
2. 选择保存草稿（Save Draft）。打开 Web `/announcements`，这条新草稿不应出现。
3. 核对内容后发布（Publish）。从公开列表点击新公告，核对标题、正文和时间。
4. 修改正文并保存草稿，再打开公开详情：访客仍应看到旧版本。确认后发布变更（Publish Changes），公开端才更新。
5. 需要撤下时，在文档操作菜单下线（Unpublish）并确认。列表移除，原详情地址返回 404。

公开路径由系统生成，不需要自行填写。删除已关闭；不要清空正文代替下线。发布和下线无需手工清缓存。

发布校验失败时，按字段提示检查文本长度、空正文和链接协议。没有发布按钮或返回 403 时，请账号管理员检查账号状态、权限到期及显式拒绝。公开页面不可用时，按[运维排错](README.md#启动失败时)检查服务并记录请求编号。

具有 `audit.read` 的账号可在“系统与审计 → 审计事件”查看公告发布/下线记录；审计不保存正文，正文历史请查看内容版本。
